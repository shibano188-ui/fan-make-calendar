# 作品マスタ（表記ゆれ辞書）の試作

「ガッシュ」「ドラクエ」「ハイキュー（!!なし）」「呪術回戦（誤字）」のような入力を、
正式表記に直してから作品を作る／探すための辞書を作る。

対象は作品（アニメ・漫画・ライトノベル・ゲーム・メディアフランチャイズ）に加えて、
アイドル・バンド・劇団・VTuber・VTuber事務所・声優。カレンダーの単位になりうるものは入れている。

現状: **55,712件 / 別名 29,466件 / かな読み 54,462件**。
実入力43件の試験で 自動36 / 確認7 / 不明0。

## 実行

```
node scripts/works-master/fetch-wikidata.mjs    # 作品の正式名・別名・知名度（約2分）
node scripts/works-master/fetch-redirects.mjs   # Wikipediaのリダイレクトとかな読み（約10分・再実行で続きから）
node scripts/works-master/resolve.mjs           # 選別・索引づくり・引けるかの試験
```

出力は `scripts/.works-master/`（gitignore 済み）。最終成果物は `master.jsonl`。

## 出どころ

- **Wikidata**: 正式名・別名・何言語版に記事があるか（知名度の目安）。CC0
- **日本語版Wikipedia のリダイレクト**: 「ぼざろ」→「ぼっち・ざ・ろっく!」のような略称の宝庫
- **DEFAULTSORT**: 記事の並び順キー。ほぼそのまま作品のかな読みになる（濁点なし・小書きなし・長音は母音に開く）

## 別名の扱いを出どころで分ける

Wikidata の別名は人が手で入れているので無条件に採用する。
Wikipedia のリダイレクトはキャラ名・楽曲名・派生作品が大量に混ざるので、
「正式名より短く、文字が同じ順に並ぶ」ものだけを略称とみなす（ドラクエ ⊂ ドラゴンクエスト）。
この選別で約1.6万件のノイズを落としている。

## 引くときの関門

上から順に落とし、下にいくほど確信度が下がる。

1. 表記の正規化で一致 → 自動で正式名に直す（記号落ち・かなカナ・ヴ揺れ）
2. かな読みで一致 → 自動（ひらがな入力）
3. 部分一致 → **自動にしない**。候補を出して選ばせる
4. 編集距離が1〜2 → 「もしかして」を出して選ばせる（誤字）

1で当たっても、明らかに知名度の高い別候補があるときは2に落とす。
「ガンダム」は記号が落ちた結果 ∀ガンダム と鍵が一致してしまうが、
機動戦士ガンダムの方が知名度が高いので確定させずに選ばせる。

## 分かっている穴

- 英題（`Cells at Work! → はたらく細胞`）は略称の選別で落ちる。日本語で入力される前提なので放置
- Wikipediaに記事がない新作・同人・地方イベントは当然入らない。自由作成の道は残す必要がある
