## 説明文（4000字以内）

**2026-08-15 時点で App Store Connect に入っている実物**（下書きではなくこれが提出内容）。

```
推しのグッズやイベントの予定を、ひとつのカレンダーにまとめるアプリです。

好きな作品をフォローすると、その作品のグッズ・イベント情報が自動で集まります。発売日や予約の締切が近づいたら通知でお知らせするので、「気づいたら受付が終わっていた」を防げます。

主な機能
・Xの告知を共有するだけで、商品名・発売日・価格をAIが読み取って予定にします。手入力はほとんど要りません
・発売日、予約の締切、受付開始の前に通知が届きます
・iPhoneのカレンダーにも書き込めるので、普段使っているカレンダーで確認できます
・みんなが投稿した情報が集まるので、自分でチェックしていなかったグッズも見つかります
・販売サイトへのリンクから、そのまま予約・購入に進めます

プレミアム（月¥500 / 年¥4,800・最初の1か月は無料）
・受付開始をその場で通知（無料プランは翌朝まとめて）
・値下げ・再入荷のお知らせ
・端末カレンダーへの自動同期
・フォローできる作品が無制限（無料プランは5作品まで）
・広告の非表示

いつでも解約できます。

利用規約（EULA） https://www.apple.com/legal/internet-services/itunes/dev/stdeula/
FanHive 利用規約 https://fanhive.jp/terms.html
プライバシーポリシー https://fanhive.jp/privacy.html
```

⚠️ **末尾3行は消さないこと**。2026-08-15、規約リンクが1つも無かったせいで
3.1.2 Business: Payments - Subscriptions で却下された。
特に1行目の **Apple標準EULA のURL** が要る。自社ドメインの規約URLだけだと
「カスタムEULA」扱いになり、App Store Connect の使用許諾契約欄に全文を登録していないと通らない
（FanHive は「Appleの標準使用許諾契約」設定なので、標準EULAのURLを書くのが正しい）。

## 年齢レーティングの回答

投稿を扱うアプリなので、**「ユーザー生成コンテンツ」に「あり（管理あり）」**を選ぶ。
通報・ブロック・24時間以内の対応を規約に明記済み（2026-08-13）→ [[fanhive-report-filter-dead-code]]

| 質問 | 回答 |
|---|---|
| 暴力・性的描写・不適切な言葉 | すべて「なし」 |
| ユーザー生成コンテンツ | **あり**（通報・ブロック・削除の仕組みがある） |
| Webアクセス（制限なし） | **あり**（購入リンクで外部サイトを開くため） |
| ギャンブル・コンテスト | なし |
| **想定年齢** | **12+**（ユーザー生成コンテンツと無制限のWebアクセスがあるため） |

## App Review に伝えること（審査メモ）

```
FanHiveは、アニメ・漫画・ゲームのグッズやイベントの予定を、ファン同士で
共有するカレンダーアプリです。

■ アカウントについて
サインインは不要です。起動してすぐすべての機能をお試しいただけます。
（メールアドレスの登録は、機種変更時のデータ引き継ぎと、有料プランの
purchase をアカウントに紐付けるためだけに使う任意の機能です）

■ 有料プランの確認方法
マイページ上部の「FanHive プレミアム」から購入画面を開けます。
Sandboxアカウントでご確認ください。

■ 外部リンクについて
商品の購入リンクは、楽天市場・Yahoo!ショッピングなどの
**物理的な商品**の販売ページを開きます。アプリ内のデジタルコンテンツの
販売ではありません。

■ 投稿の管理について
不適切な投稿は各投稿の詳細画面から通報でき、通報後はその方の画面に
表示されなくなります。投稿者名をタップして開くプロフィールから、
その方をブロックすることもできます。24時間以内に対応します。
連絡先: contact@fanhive.jp
```
