## 2. 満たしていることを確認したもの

### 2.1 クラッシュ・完成度

- 他に用途説明が要るAPIを触っていない。位置情報・マイク・連絡先・モーション・音声認識は
  コードに一切出てこない（`geolocation` / `mediaDevices` / `SpeechRecognition` を全文検索）
- カレンダープラグインの `checkAllPermissions` は `EKEventStore.authorizationStatus(for:)` を
  読むだけで、リマインダーの許可要求はしない（プラグインのSwiftを読んで確認）。
  → `NSRemindersFullAccessUsageDescription` は不要
- RevenueCat の iOSキーがバンドルに入っている。**入っていないと購入画面が
  「ただいまお支払いの準備中です」になり、2.1で即落ちる**
- 「準備中…」の表示はICS URLを作る一瞬だけ（プレミアムの折りたたみの中）
- `?demo=1` はオンボーディングの体験用で、画面に「投稿（例）」「今は投稿を押しても
  登録はされません」と出る。隠し機能(2.3.1)ではない

### 3.1.2 定期購読（購入画面で実機確認）

購入ボタンと同じ画面に、価格 `¥500/月`、`最初の1か月は無料。以降は月¥500で自動更新されます。
いつでも解約できます。`、**利用規約 / プライバシーポリシー / 購入を復元** が並んでいる。
別画面送りにしていない。

### 5.1.1 データ収集

- 会員登録なしでアプリのすべての機能が使える（匿名アカウントを自動作成）
- 購入に会員登録を要求しない。購入画面に登録の入口を置いていない（8/17に修正済み）
- アカウント削除がマイページの設定リスト最終行にある。2段階で、
  「投稿・いいね・保存した予定を含むすべてのデータが削除されます」と明示

## 3. 残っているリスク

### 中: 投稿前の自動フィルタが無い（1.2）

1.2 は「不適切な素材が投稿されるのを防ぐ手段」を求める。今は**通報・ブロック・24時間以内の
手動削除**で運用していて、投稿時の自動チェックが無い。

ただし 5回の審査で 1.2 は一度も指摘されていない。8/15の情報要求への回答で通報・ブロックの
仕組みを説明し、審査はそのまま進んだ。
NGワード判定を入れる手もあるが、**誤検知で審査員の投稿が弾かれるほうが害が大きい**ので、
今回は入れない判断。指摘されてから足すほうが安全。

### 低: 第三者の権利物（5.2.1）

作品名と商品画像を扱う。画像・価格・リンクは楽天/Yahoo!ショッピングのアフィリエイトAPI由来で
規約上許諾されており、作品名はユーザーがフォローする**テキストのラベル**としてのみ出る。
8/15の回答でこの内容を説明済み。

## 4. App Store Connect を実際に見た結果（2026-08-20）

### 直さないと出せない / 出すと危ないもの

1. **Apple Developer Program の使用許諾契約が未同意。**
   アプリ一覧に「更新された契約に同意する必要があります」の警告が出ている。
   **同意するまで新規提出も更新もできない。** Account Holder 本人がアカウントページで同意する

2. **App Store のスクリーンショット1枚目（購入画面）が旧UI。**
   CTAが **「メールアドレスを登録する」** のまま＝ Apple が 5.1.1(v) で却下したその画面。
   今のビルドは「初月無料で始める」。差し替え必須

3. **App Store のスクリーンショット2枚目（投稿画面）に「写真から読み取る」が写っている。**
   ビルド6で削除した機能。2.3.3（スクリーンショットは実際の使用を示すこと）に触れる。差し替え必須

4. **サブスク2つ（月払い・年払い）の審査用スクリーンショットも同じ旧購入画面。**
   IAPの審査担当が見るのはこの画像なので、5.1.1(v) を自分から再提示することになる。差し替え必須

5. **メモ欄の PERMISSIONS に写真ライブラリが無い。** ビルド6から背景画像の選択で
   写真の許可を求めるので1行足す。カメラは書かない（使わないので）

6. **メモ欄の末尾「NOTE ON OUR REPLY ABOUT BUILD 5」が浮いている。**
   その返信は下書きのまま届いていないので、審査員には何のことか分からない。段落ごと削除する

#### メモ欄の差し替え（この2箇所だけ）

```
PERMISSIONS
Notifications (reminders for release dates and pre-order deadlines), Calendar (writing an event
to the iOS Calendar, at the user's request), Photo Library (choosing a background image for the
calendar; the photo stays on the device). The app does not use the camera.
App Tracking Transparency (banner ads).
```

`NOTE ON OUR REPLY ABOUT BUILD 5` の段落は丸ごと消す。
