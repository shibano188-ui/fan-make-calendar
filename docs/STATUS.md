## 2026-09-20 に変えたところ（画面）

- **予定パネル**（探す・カレンダーの一覧・ホームで共通・`ItemCard` の list/wide/compact）: 1行1件。画像の下に「締切まで あと◯日」、右下にいいね・リアクション・通知を大きめに。購入リンクはカードに出さない（PR表記が要るので詳細だけ）
- **リアクション**: 1人が何個でも押せる（`event_stamps`・古い iOS の `reactions` はトリガーで写す）。カードは一番多いスタンプとその数。押すと下からパネル、1つ押したら閉じる。スタンプに白いふち
- **通知ベル**: 1回押すだけで ON／OFF。保存していない予定でも押せて、押すと保存もする。何を ON にするか・「当日のみ」は通知の設定で選ぶ
- **検索**: 探す・カレンダー・ホームの上部。虫眼鏡を押すと 左端へ滑る→揺れる→伸びる→入力欄（`ExpandingSearch`）。入力中は下のバーを隠す
- **探す**: 「グッズ ⇄」の切り替え、未読の割合を円で見せる「未読」、カレンダーと同じ作品の並び（`WorkChipsRow`）
- **ホーム**: 一番上に値下がりのバー＋虫眼鏡、作品の並び、「フォロー作品の新着（見たものは除く）→ 受付中 → 人気」。見出しは上に貼りついて畳める
- **予定詳細**: 作品・タイトル → 画像 → 段階の流れ（予約開始前→予約受付中→予約終了→発売中→発売済み）→ 日付と場所 → ピン → 価格 → パネル → タブ（詳細・リンク・在庫情報・Contributors）。日付が曖昧なら「未確定」。在庫の報告は簡易チェックあり（`src/lib/stockCheck.ts`）
- **通知の設定**: 作品ごとの通知の切り替えをここに集めた（フォロー中のページからは外した）
- **状態の呼び方**: 「締切」は締め切られる日のことだけ。状態は 予約開始前／予約受付中／予約終了／発売前／発売中／発売済み

## 競合

OshiLock（アイドル向け・iOS のみ・2026-06 リリース）が仕組みのかなり近いアプリ。
向こうに無いのは**グッズの買い逃し防止**（購入リンク・締切・値下げ再入荷）と Android、無料枠の広さ。
向こうは Expo の OTA で **iOS にも審査なしで画面の更新を届けている**。こちらは iOS だけ審査待ちになるので、更新の速さで負けやすい。
